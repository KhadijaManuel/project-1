 HR Management System 
 ModernTech Solutions

 Description
A full-stack HR web app for managing employees, attendance, leave, payroll, and reviews.

 Tech Stack
- Frontend: Vue.js + Tailwind CSS
- Backend: Node.js + Express
- Database: MySQL

 Setup Instructions for running the application
Clone the repo
Run `npm install` in backend and frontend folders
Add `.env` file for DB & JWT
Run backend: `npm run dev`
Run frontend: `npm run serve`

## Features
- Secure login (JWT-based)
- Role-based dashboard
- Export data as CSV/PDF(payslips and attendance)
- Fully responsive UI
- add and remove employees data from 1 single application
